# 🎬 Movie Recommender System

An interactive movie recommendation web app built using **Streamlit**.  
It recommends movies based on content similarity, shows posters and overviews, allows users to save favorites, and supports genre filtering.

---

## ✨ Features

- 🔍 **Search** for any movie by title
- 🧠 **Content-based recommendation** using TF-IDF & cosine similarity
- 🎭 **Genre filtering**
- ⭐ **Movie ratings & overview**
- 🖼️ **Movie posters** via TMDB API
- ❤️ **Add to Favorites** (Session-based)
- 🌗 **Light/Dark mode toggle** (via config)
- 📌 **Favorites preview panel**

---

## 🛠 Tech Stack

| Layer        | Tools Used                      |
|--------------|----------------------------------|
| Frontend UI  | Streamlit                        |
| ML Engine    | scikit-learn (TF-IDF, cosine sim)|
| API          | TMDB API                         |
| Data Source  | TMDB 5000 Movies & Credits CSV   |
| Language     | Python                           |
